# Thala 7 Sneaker Store

A multi-page e-commerce web application for a sneaker store designed using pure HTML5 and CSS3.

## Pages Included

- `index.html`: Landing page featuring Flexbox navbar, split hero section, and service achievements banner.
- `product.html`: Product detail view with gallery thumbnails, pricing, tax details, and add-to-cart action.
- `cart.html`: Shopping cart table with quantity controls, coupon input, and order billing breakdown.
- `payment.html`: Two-column checkout screen with payment tabs (Card, Crypto, Bank) and order summary.
- `style.css`: Custom stylesheet using Flexbox layouts without external frameworks.
